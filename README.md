# SortAcademy

SortAcademy is an interactive web-based learning platform designed to help students understand sorting algorithms through visualisation, practice and assessment.

## Features
- Interactive visualisations of sorting algorithms
- Step-by-step execution (play, pause, step)
- Practice exercises for active learning
- Quiz and assessment modes
- Gamification (points, badges, progress tracking)
- Accessibility features (high contrast, dyslexia-friendly font, adjustable text size)

## Technologies Used
- React
- JavaScript
- CSS
- LocalStorage (for user progress)

## How to Run
1. Install dependencies:
   npm install

2. Start the app:
   npm start

3. Open in browser:
   http://localhost:3000

## Project Structure
- src/ → main application code
- public/ → static files

## Notes
- No personal data is collected
- All data is stored locally in the browser
